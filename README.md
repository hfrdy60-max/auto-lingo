# AUTO LINGO 🚗
پلتفرم آموزش زبان تخصصی خودرو با توضیحات فارسی.

## نسخه اول
- رابط کاربری فارسی و راست‌چین
- جست‌وجوی اصطلاحات فنی خودرو
- دسته‌بندی سیستم‌های خودرو
- نمایش معنی، تلفظ، توضیح و مثال انگلیسی
- آزمون کوتاه چهارگزینه‌ای
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید. این نسخه فعلاً بدون سرور و بدون نیاز به نصب اجرا می‌شود.

## نقشه راه
1. نسخه اولیه واژگان و آزمون
2. حساب کاربری و ذخیره پیشرفت
3. بانک اطلاعاتی گسترده قطعات و اصطلاحات
4. آموزش هوشمند با هوش مصنوعی
5. محتوای اختصاصی برندها و مدل‌های خودرو

> نکته فنی: اطلاعات حساس تعمیراتی مانند پین‌آوت، مقادیر ولتاژ و مقاومت باید فقط با منبع معتبر همان خودرو منتشر شوند.
