# AUTONEX — گزارش QA ادغام پایلوت Autel v0.3
تاریخ: 2026-11-14

## دامنه
پایلوت Autel MaxiSys MS906 Pro / MS906 Pro-TS بر پایه فایل‌های v0.3 تحویلی AI-3 و راهنمای رسمی ثبت‌شده با ویرایش US V2.1. این کار فقط پایلوت Autel را پوشش می‌دهد؛ تولید انبوه برندها شروع نشده است.

## اصلاح بسته‌بندی
- داده‌ها در مسیر پایدار data/technical_reference/autel_ms906pro_v03/ قرار گرفتند.
- نام فایل‌ها پاک‌سازی شد: entries.json، device.json، sources.json و سه فایل schema.
- فایل‌های آپلودی ریشه حذف یا بازنویسی نشدند. نسخه اولیه validator ارسالی AI-3 برای سابقه آرشیو شد و validate_pilot.py ریشه اکنون wrapper اعتبارسنج استاندارد v0.3 است.
- فایل تکراری service_functions (3).json به مجموعه استاندارد وارد نشد.
- README ریشه که با متن تحویل پایلوت جایگزین شده بود، به محتوای اصلی پروژه بازگردانده شد و بخش معرفی نسخه v0.3 به README افزوده شد.

## منابع و صفحات
- یک سند رسمی در فهرست منبع موجود است: راهنمای MaxiSys MS906 Pro / Pro-TS، ویرایش US V2.1.
- ۳۹ صفحه متمایز در citationهای رکوردها و مشخصات دستگاه استفاده شده است.
- manifest منبع ۴۱ صفحه دارد؛ دو صفحه مقدماتی رومی ii و iii در manifest مانده‌اند ولی در citationهای رکوردها استفاده نشده‌اند.
- همه ارجاع‌ها به source_id موجود اشاره می‌کنند و صفحات ارجاع‌شده خارج از manifest نیستند.
- شماره ویرایش PDF، نسخه نرم‌افزار نصب‌شده روی دستگاه نیست. نسخه نرم‌افزار دستگاه همچنان null ثبت شده است.

## اصلاح اعتبارسنج
- validator قبلی AI-3 به‌دلیل mismatch مسیر ورودی و fallback ناسازگار با type union برای نقش CI قابل اتکا نبود.
- validator جدید tools/validate_autel_v03.py با مسیرهای canonical اجرا می‌شود و type: [string, null] را به‌درستی بررسی می‌کند.
- بررسی schema، فیلدهای الزامی، enum/const، pattern، روابط، مقصدها، نسخه سند، وضعیت ترجمه، وضعیت مثال و پوشش صفحات در اسکریپت مستقل پیاده‌سازی شده است.
- Workflow مستقل در .github/workflows/autel-v03-validation.yml اضافه شد؛ این Workflow علاوه بر بانک داده، با node --check source-academy.js نحو JavaScript آکادمی را نیز بررسی می‌کند.

## اتصال به نرم‌افزار
- دوره Autel در source-academy.js از بانک canonical v0.3 بارگذاری می‌شود.
- مشخصات دستگاه و رجیستری منابع نیز بارگذاری شده و نام سند، ویرایش، VCI و URL منبع در معرفی دوره منعکس می‌شود.
- هر ۴۰ سناریوی آموزشی در پنل مجزا نمایش داده می‌شود؛ فهرست واقعیت‌های فنی و شماره صفحه‌های پشتوانه نیز جداگانه نشان داده می‌شود.
- وضعیت technical=verified با توضیح محدودیت نمایش داده می‌شود تا با تأیید مستقل AUTONEX یا مشاهده دستگاه فیزیکی اشتباه نشود.
- وضعیت همه ترجمه‌ها به‌صراحت draft_unreviewed اعلام می‌شود.
- متن معرفی آکادمی و cache-buster فایل‌های JS/CSS به‌روز شد.

## محدودیت‌های باز
1. بازبینی انسانی ترجمه و تلفظ ۴۰ مدخل انجام نشده است.
2. تأیید فنی مستقل با PDF صفحه‌به‌صفحه و تطبیق روی دستگاه فیزیکی انجام نشده است.
3. نسخه نرم‌افزار دستگاه در منبع مشخص نیست.
4. اجرای runtime در مرورگر و اندازه‌های مختلف موبایل هنوز انجام نشده؛ اتصال کد به داده و به‌روزرسانی cache-buster انجام شده، اما تا موفقیت workflow و مشاهده سایت، انتشار زنده را قطعی نمی‌دانیم.

## تصمیم QA
PASS برای ادغام در محیط آموزشی با هشدارهای روشن؛ NOT APPROVED برای تأیید فنی/ترجمه نهایی یا تولید انبوه.
گام مجاز بعدی پس از موفقیت validator و آزمون UI: بازبینی ترجمه و یک پایلوت محدود Launch، نه تولید هم‌زمان برای تمام برندها.
